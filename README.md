# Urban Spark Writer

An intuitive, modern web application designed for seamless content creation, editing, and management.

## 🚀 Features

- **Rich Text Editing:** Clean interface tailored for distraction-free writing.
- **Backend Integration:** Powered by Supabase for authentication and database management.
- **Fast Development Setup:** Built with Vite and React for lightweight, high-performance execution.

## 🛠️ Tech Stack

- **Framework:** React + TypeScript
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Package Manager:** [Bun](https://bun.sh/)
- **Database & Auth:** [Supabase](https://supabase.com/)
- **UI & Styling:** Tailwind CSS + Shadcn UI
